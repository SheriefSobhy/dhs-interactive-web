Personal finances
stay personal.

Flooth’s local mode keeps financial records in an app-private database on your device. Core financial tracking works offline and doesn’t need an account or a Flooth API connection.

You can also create an encrypted backup protected by a passphrase you choose, then save it to a location you select.
